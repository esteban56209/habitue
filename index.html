Simple pour vous, simple pour vos clients

1

Créez votre carte

Choisissez le nombre de tampons et la récompense. Exemple : 10 passages = 1 café offert.

2

Posez le QR code au comptoir

Imprimez l'affiche fournie. Vos clients la scannent avec l'appareil photo de leur téléphone.

3

Validez avec votre code PIN

À chaque passage, vous tapez votre code secret sur le téléphone du client. Le tampon s'ajoute.

Fini les cartes perdues

La carte reste dans le téléphone du client. Il la retrouve à chaque visite en scannant le QR code.

Vous savez enfin qui revient

Nombre de clients fidèles, passages du mois, récompenses offertes : tout est dans votre tableau de bord.

Pas de triche

Seul votre code PIN valide un tampon. Après plusieurs codes faux, la validation se bloque.

Rien à installer

Ni pour vous, ni pour vos clients. Tout fonctionne dans le navigateur, sur téléphone comme sur ordinateur.
